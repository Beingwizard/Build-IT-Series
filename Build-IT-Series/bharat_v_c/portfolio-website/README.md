# Portfolio Website

This portfolio website showcases my professional profile and suitability for an architect role. It is built using HTML, CSS, Bootstrap, and JavaScript, featuring a clean and responsive design.

## Project Structure

- **index.html**: The main entry point of the portfolio website, containing the home page structure and content.
- **assets/**: Contains all the assets for the website.
  - **css/**: Custom styles and Bootstrap CSS.
    - **style.css**: Custom styles defining layout, colors, and fonts.
    - **bootstrap.min.css**: Minified version of Bootstrap's CSS framework.
  - **js/**: Custom JavaScript and Bootstrap JS.
    - **main.js**: Custom JavaScript for interactivity and dynamic content.
    - **bootstrap.min.js**: Minified version of Bootstrap's JavaScript library.
- **pages/**: Contains additional pages for the website.
  - **projects.html**: Showcases work and projects relevant to the architect role.
  - **about.html**: Details background, skills, and suitability for the architect role.
  - **contact.html**: Includes a contact form for potential employers or clients.

## Setup Instructions

1. Clone the repository or download the project files.
2. Open `index.html` in a web browser to view the portfolio website.
3. Customize the content in the HTML files and styles in `style.css` as needed.

## Purpose

This portfolio website serves as an identity for my job search, highlighting my skills and projects that demonstrate my qualifications for an architect role.
